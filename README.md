# 통합과학 메타인지 진단 파일럿

고1·고2 학생과 학부모를 위한 통합과학 메타인지 진단 파일럿 랜딩페이지입니다.

이 서비스는 온라인 강의, 문제은행, 만능 AI 튜터가 아니라 학생이 통합과학 개념을 실제로 이해하고 있는지, 어디에서 확신하고 틀리는지, 어떤 오답 원인부터 복습해야 하는지 보여주는 진단형 파일럿입니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

Vercel에서 Next.js 프로젝트로 배포하면 됩니다.

## 포함하지 않은 것

- 백엔드
- 데이터베이스
- 인증
- 결제
- API route
- AI API 연동
